# 喵記 Meow Diary

一個讓人練習覺察和表達情緒的小網頁。選一個最接近現在的感覺，就會有一隻戴著小配件的貓咪跑進窗外的草原；窗外的天空也會跟著你的心情變天氣。房間裡還住著一隻你養的貓，會陪你聊天、跳上床睡覺。

不用安裝、不用註冊，打開網頁就能用。所有記錄只存在你自己的瀏覽器裡。

**線上試玩：<https://ruby510054.github.io/meow/>**

![喵記主畫面：窗外的草原、房間和寵物](docs/main.png)

## 為什麼做這個

心情不好的時候，我們常常只知道「不舒服」，卻說不出那到底是什麼感覺：是失望、委屈、孤單，還是累了？喵記想做的，就是讓「說出自己的情緒」這件事變得輕鬆一點、可愛一點，每天花幾秒鐘，跟一隻貓說說現在的感覺。

練習辨認和記錄情緒，有一些研究上的好處：

- **說出情緒的名字，情緒會緩和一點**：研究發現，把感受用文字說出來（例如「我現在很焦慮」），大腦中和情緒反應有關的區域活動會降低。光是替情緒命名，就是一種調節情緒的方式（Lieberman 等人，2007）
- **分得越細，越能好好面對**：能分辨細微情緒差別的人，例如知道自己是「失望」而不只是「不開心」，在面對不舒服的情緒時，比較能找到合適的方法應對，也比較不會用傷害自己的方式來逃避（Kashdan、Barrett 與 McKnight，2015）。這也是喵記準備了 47 個情緒詞，而不只有「開心」和「難過」的原因
- **寫下來，對身心都有幫助**：把情緒經驗寫下來的人，在後續的研究追蹤中，身心健康上有正面的改變（Pennebaker，1997）
- **長期記錄，看見自己的規律**：記錄久了，就能從日曆上看出心情的變化，例如睡不好的隔天比較容易煩躁、和朋友見面後通常比較放鬆，更認識自己

喵記的四個區塊，是用「舒不舒服（愉悅度）」和「能量高低」來分類情緒，這個做法來自心理學的情緒環狀模型（Russell，1980）。窗外的心情天氣，也是用這兩個數值畫出來的。

> 喵記是陪你練習覺察情緒的小工具，不能取代專業的協助。如果你最近常常覺得撐不住，或是有傷害自己的念頭，請找信任的人聊聊，或撥打專線：
> - **安心專線 1925**（24 小時，免付費）
> - **生命線 1995**
> - **張老師 1980**

## 有什麼

### 記錄心情
- 先選「能量高低 × 舒不舒服」四個區塊之一，再從 13 個情緒家族、47 個情緒詞裡挑一個最接近的，每個詞都有一句說明
- **混合情緒**：可以跨區塊複選，例如同時「難過」又「感激」
- **說不上來**：改成記錄身體感覺（胸口悶悶的、肩膀很緊…）和跟什麼有關（工作、家人…）
- 一天可以記很多次，每筆都可以寫幾句話，之後也能修改、刪除、補記

![記錄心情：選了「難過」，窗外就下起雨來](docs/record.png)

### 心情天氣
窗外的天空會依照心情變色，還會有天氣（不會出現文字，直接用畫面感受）：開心有活力是晴天、平靜是粉紫色的天空和彩虹、煩躁會起風、生氣會打雷、難過會下雨。顏色是用每個情緒的「愉悅度」和「能量」數值連續混合出來的，所以每種心情的天空都有一點不同。

![四種心情天氣：晴朗、彩虹、起風、下雨](docs/weather.png)

### 每種情緒都有自己的配件
47 個情緒各有一個小配件，例如興奮戴派對帽、有壓力頭上頂鬧鐘、累了戴睡帽、被愛會飄愛心。每次記錄時配件會隨機配一個柔和的顏色，選之前可以先預覽、也可以重抽。

![所有情緒的配件](docs/accessories.png)

### 窗外的草原、房間裡的寵物
- **草原上的小貓**：最近 7 次記錄的貓咪會在草原上散步、追逐、打鬧、依偎、幫彼此理毛，偶爾還會自言自語。每隻貓的動作會依照那個情緒的「能量」和「愉悅度」不同：能量高的走得快、愛蹦跳，能量低的常常趴著睡覺；心情舒服的愛找別的貓玩，不舒服的喜歡自己待著。有些情緒還有專屬動作，例如興奮會原地轉圈、坐立不安會來回踱步、害怕會躲到草叢後面發抖、孤單會一個人坐在草原邊邊、被愛和感激會一直去蹭別的貓。點牠們會喵一聲、說出那天的心情；點草地可以放小魚乾，也可以踢毛線球
- **你的寵物**：住在房間裡，平常窩在書桌下的貓床，會自己跑去玩、跳上床睡覺、坐沙發。牠會戴著你現在心情的配件，記得你今天說過的話，主動找你聊天。可以幫牠取名字、選花色，也會記得你們一起生活了幾天
- **房間**：書桌、床、沙發、魚缸、貓耳時鐘、小燈泡……

### 窗簾
不想看窗外的時候，可以把窗簾拉起來；也可以換成喜歡的窗簾樣式。

- **拉窗簾**：抓住窗簾往中間拖就會拉上，往兩邊拖就拉開，可以停在任何位置；直接點一下窗簾，會整個拉開或拉上。也可以按窗台左下角的「拉上窗簾／拉開窗簾」按鈕
- **換窗簾**：按窗台左下角顯示窗簾名稱的按鈕（例如「輕紗」），每按一次換一種
  - **輕紗**（預設）：半透明的白紗，拉上後還隱約看得到外面的草原和天氣
  - **格子布**：主題色的格子布，拉開時用蝴蝶結綁起來，下方縫著貓咪臉布貼
  - **波浪短帘**：掛在窗戶上方的波浪布邊，往下拖會像捲簾一樣降下來，上面印著小貓掌
- 窗簾的顏色會跟著主題色變，選了哪一種、拉到哪裡都會記住

![窗簾：輕紗拉開、輕紗拉上、格子布拉一半、波浪短帘拉下來](docs/curtains.png)

### 出門走走
按窗戶下方的「出門走走」，就能走出房間到草原上。窗框和窗簾都不見了，整個畫面就是草原，你的寵物也會跟著一起出門。

- 寵物會跟草原上的小貓一起玩：追逐、打鬧、依偎、搶小魚乾、玩毛線球
- 在戶外看到的貓咪比隔著窗戶看大很多，可以近距離摸摸牠們；點你的寵物會喵喵叫、呼嚕，還會冒愛心
- 點草地一樣可以放小魚乾，心情天氣也會跟著出現在戶外
- 按左上角的「回家」或鍵盤的 Esc 就會回到房間，寵物也會一起回家
- 記錄心情和心情日曆只能在房間裡使用，戶外就是單純放鬆散步的地方

![出門走走：寵物跟著一起到草原上](docs/outside.png)

## 開始使用

### 線上使用
直接打開 <https://ruby510054.github.io/meow/> 就可以了。建議使用 Chrome、Edge、Firefox 或 Safari 的新版本。

### 在自己的電腦上使用
下載或 clone 這個專案，用瀏覽器打開 `index.html`。

### 放到你自己的 GitHub Pages
1. Fork 這個 repo（或把專案推到你自己的 repo）
2. 到 repo 的 **Settings → Pages**
3. **Source**選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 **Save**
4. 等一兩分鐘，就能在 `https://<你的帳號>.github.io/<repo 名稱>/` 打開

## 資料與隱私

- 記錄只存在**你自己的瀏覽器**裡（localStorage），不會上傳到任何地方
- 清除瀏覽器資料、換瀏覽器或換電腦時，記錄會看不到。請偶爾按網頁最下面的「下載備份檔」，把備份檔存在安全的地方，之後可以用「從備份檔讀取」讀回來（讀取是合併，不會覆蓋現有的記錄）
- 想重新開始的話，按網頁最下面的「清除資料」：可以只清掉第一次打開時附的示範資料，也可以清除所有心情記錄，或連寵物和設定一起重設
- 注意：直接打開本機的 `index.html`，和打開 GitHub Pages 的網址，對瀏覽器來說是兩個不同的網站，記錄不會互通，需要用備份檔搬過去

## 自訂情緒

情緒的分類寫在 [`mood.json`](mood.json)：

```text
quadrants（4 個象限：能量高低 × 舒不舒服）
└─ families（情緒家族，例如「悲傷」）
   └─ emotions（情緒詞）
        id、label.zh、desc（說明）
        valence（愉悅度，-1 ~ 1）、arousal（能量，-1 ~ 1）
special_options：mixed（混合情緒）、unsure（說不上來）
```

為了讓網頁只用一個檔案就能打開，`index.html` 裡放了一份一模一樣的內容（在 `<script type="application/json" id="emotionData">` 裡）。改了 `mood.json` 之後，把那一段整段換成新的內容就好。

- `valence`、`arousal` 決定心情天氣的顏色
- 新增的情緒詞如果沒有專屬配件，會自動使用同一個家族的配件
- 新增的家族要對應到哪一種貓咪表情，寫在 `index.html` 的 `FAMILY_FACE`

## 技術

- 整個網頁就是一個 `index.html`：純 HTML、CSS、JavaScript，不需要安裝套件，也不需要建置
- 貓咪、家具、天氣都是用程式畫的 SVG
- 背景音樂和呼嚕聲用 Web Audio API 即時合成；喵叫聲是剪輯過的真實錄音，直接嵌在檔案裡
- 字型使用 Google Fonts 上的 [jf open 粉圓（Huninn）](https://fonts.google.com/specimen/Huninn)，需要網路才會載入，沒有網路時會改用系統字型

```text
.
├── index.html   # 整個網頁
├── mood.json    # 情緒分類
├── README.md
├── LICENSE      # MIT 授權
└── docs/        # README 用的截圖
```
